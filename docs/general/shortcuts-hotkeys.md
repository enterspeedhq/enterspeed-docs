# Shortcuts & Hotkeys

Here is a list of hotkeys and shortcuts when using the Enterspeed Management App:

## Global

| Hotkey         | Action                          |
| -------------- | ------------------------------- |
| <kbd>Esc</kbd> | Closes the currently open modal |

## Editing schema

| Hotkey                                           | Action                |
| ------------------------------------------------ | --------------------- |
| <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + <kbd>S</kbd>  | Saves draft of schema |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> | Format schema         |
