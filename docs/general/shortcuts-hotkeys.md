# Shortcuts & Hotkeys

Here is a list of hotkeys and shortcuts when using the Enterspeed Management App:

## Global

| Hotkey         | Action                          |
| -------------- | ------------------------------- |
| <kbd>Esc</kbd> | Closes the currently open modal or pane |
| <kbd>Ctrl</kbd> / <kbd>⌘</kbd> + <kbd>K</kbd> | Opens the Commandbar |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>1-9</kbd> | Navigates the side menu |

## Editing schema

| Hotkey                                           | Action                |
| ------------------------------------------------ | --------------------- |
| <kbd>Ctrl</kbd> / <kbd>⌘</kbd> + <kbd>S</kbd>  | Saves draft of schema |
| <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>F</kbd> | Format schema         |
