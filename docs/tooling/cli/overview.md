# CLI

The Enterspeed CLI lets you work with your Enterspeed tenant for all sorts of tasks like managing environments, source groups and creating and deploying schemas. You can work with the CLI locally or you can use it in a CI/CD pipeline it's up to you and how you workflow is.

Go to our Github repository to find download links and documentation:

[Download and installation](https://github.com/enterspeedhq/enterspeed-cli#installation)  
[Documentation](https://github.com/enterspeedhq/enterspeed-cli#usage)
