This page lists the Enterspeed packages you can install and their support status.
Use it to check that the version you run is still supported, and when to upgrade.

<Note>
  A software bill of materials (SBOM) is available for each supported version.
  SBOMs are shared with customers on request. See [Requesting an SBOM](#requesting-an-sbom).
</Note>

Last updated: 2026-11-24

## Support status

- **Active**: fully supported. New features, bug fixes and security fixes.
- **Maintenance**: security fixes only, for 12 months. The version then becomes legacy.
- **Legacy**: no longer updated. Move to a supported version or the replacement package.

We announce on this page at least 12 months before an active version moves
to maintenance. The dates are in the table below. A version can become legacy
earlier if its host platform (for example Umbraco or Sitecore) reaches end of life.
