---
title: Filter Expressions
---

Filter expressions are used when doing lookups in JSON or JavaScript schemas.

Below is a list of examples of what you can do with the filter.

<Tip>
If you are using JavaScript and your filter contains expressions, it's often easier to use string interpolation instead of string concatination. See [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Template_literals#string_interpolation) .
</Tip>

<Info>
If you are comparing values containing URI special characters, you should URI encode the value in your filter expression. See [MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/encodeURIComponent).

```javascript
filter(`originParentId eq '${encodeURIComponent(sourceEntity.originId)}'`)
```
</Info>

## Examples

Examples of supported binary operators & expressions:

<Tabs>
<Tab title="JavaScript">

```javascript title="EQUALS operator"
// Property value equal to constant string value
originId eq '100'

// Property value equal to expressed string value
originId eq '${sourceEntity.properties.selectedOtherPageId}'

// Property value is null
originParentId eq null

// Property value equal to integer value
properties.price eq 9

// Property value equal to decimal value
properties.price eq 9.99

// Property value equal to boolean value (true/false)
properties.isFeatured eq true
```

<Tabs>
<Tab title="JavaScript">

```javascript title="An array contains any matching value:"
// Contains specific redirect with constant string value
redirects/any(r: r eq '/old-page')

// Contains specific tags with expression string value
properties.tags/any(t: t eq '${sourceEntity.properties.selectedTag}')

// Contains articles that feature, matching constant boolean value
properties.articles/any(a: a.isFeatured eq true)

// Contains an article that is both featured and in the sport category
properties.articles/any(a: a.isFeatured eq true and a.category eq 'sport')

// Contains either tag
properties.tags/any(t: t eq 'news' or t eq 'sport')

// Contains both tags
properties.tags/any(t: t eq 'news') and properties.tags/any(t: t eq 'sport')

// Articles tagged news or sport
type eq 'article' and (properties.tags/any(t: t eq 'news') or properties.tags/any(t: t eq 'sport'))

// Contains a featured article in either category
properties.articles/any(a: a.isFeatured eq true and (a.category eq 'news' or a.category eq 'sport'))
```

</Tab>

<Tab title="JSON">

```javascript title="An array contains any matching value:"
// Contains specific redirect with constant string value
redirects/any(r: r eq '/old-page')

// Contains specific tags with expression string value
properties.tags/any(t: t eq '{p.selectedTag}')

// Contains articles that feature, matching constant boolean value
properties.articles/any(a: a.isFeatured eq true)

// Contains an article that is both featured and in the sport category
properties.articles/any(a: a.isFeatured eq true and a.category eq 'sport')

// Contains either tag
properties.tags/any(t: t eq 'news' or t eq 'sport')

// Contains both tags
properties.tags/any(t: t eq 'news') and properties.tags/any(t: t eq 'sport')

// Articles tagged news or sport
type eq 'article' and (properties.tags/any(t: t eq 'news') or properties.tags/any(t: t eq 'sport'))

// Contains a featured article in either category
properties.articles/any(a: a.isFeatured eq true and (a.category eq 'news' or a.category eq 'sport'))
```

</Tab>
</Tabs>

<Info>
Conditions combined with `and` inside `any` must all match the same item. `properties.articles/any(a: a.isFeatured eq true and a.category eq 'sport')` only matches if one article is both featured and in the sport category, not if one article is featured and another is in the sport category.

An `and` that no single item can satisfy isn't an error, it just never matches. `properties.tags/any(t: t eq 'news' and t eq 'sport')` finds nothing, because no tag is both. To match source entities that have both tags, use two `any` joined with `and`, as in the "Contains both tags" example.
</Info>

<Tabs>
<Tab title="JavaScript">

```javascript title="An array doesn't contain a matching value:"
// Doesn't contain a specific redirect
not redirects/any(r: r eq '/old-page')

// Doesn't contain a specific tag with expression string value
not properties.tags/any(t: t eq '${sourceEntity.properties.excludedTag}')

// Articles that aren't tagged as archived
type eq 'article' and not properties.tags/any(t: t eq 'archived')
```

</Tab>

<Tab title="JSON">

```javascript title="An array doesn't contain a matching value:"
// Doesn't contain a specific redirect
not redirects/any(r: r eq '/old-page')

// Doesn't contain a specific tag with expression string value
not properties.tags/any(t: t eq '{p.excludedTag}')

// Articles that aren't tagged as archived
type eq 'article' and not properties.tags/any(t: t eq 'archived')
```

</Tab>
</Tabs>

<Info>
`not` in front of `any` also matches source entities that don't have the array, or where it's `null` or not an array.
</Info>

<Warning>
Inside `any`, compare the item with `eq` and combine comparisons with `and` and `or`. Keep the item on the left (`t eq 'news'`, not `'news' eq t`), and put conditions on the source entity itself outside `any`. Otherwise the filter can match nothing, without an error.

The following aren't supported and return a validation error:

- `ne` inside `any`, for example `properties.tags/any(t: t ne 'archived')`. To match source entities where no item equals a value, use `eq` and put `not` in front of `any`: `not properties.tags/any(t: t eq 'archived')`.
- `in` inside `any`. Use `or` instead, for example `properties.tags/any(t: t eq 'news' or t eq 'sport')`.
- `eq null` inside `any`.
- `any` inside `any`, and `all`.
- `not` anywhere other than directly in front of `any`.
- An `any` where `and` over `or` groups expands to more than 256 combinations, for example nine `(a or b)` groups combined with `and`. A plain `or` list isn't limited. Reduce the number of `or` groups combined with `and`.
</Warning>

```javascript title="Check whether the element exists in this collection"
// Finds matches in predefined integers array
properties.favoriteId in (100, 200)

// Finds matches in predefined strings array
properties.color in ('blue', 'red', 'green')

// Finds matches in favorites selection (array of integers)
properties.favoriteId in (${sourceEntity.properties.favoriteIds})

// Finds matches in colors selection (array of strings)
properties.color in (${sourceEntity.properties.colors.map(c => `'${c}'`)})
```

<Tab title="JavaScript">

```js title="Full example"
export default {
  // ...
  properties: function (sourceEntity, context) {
    return {
        // ...
        sportArticles: context
                .reference('featuredSportArticle')
                .filter(`type eq 'article' and properties.tags/any(t: t eq '${sourceEntity.properties.tag}')`)
                .orderBy({ propertyName: 'properties.metaData.sortOrder', direction: "asc"})
                .limit(5)
    }
  },
};
```

            "orderBy": {

              "sort": "asc"
            },
            "top": 5
        }

    "var": "article",
    "items": {
        "type": "object",
