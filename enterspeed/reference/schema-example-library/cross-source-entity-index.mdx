---
title: Cross source entity index
---

When working with [Index schemas](/enterspeed/reference/js/index-schema/intro) you might have noticed that it's not possible to directly combine data from multiple source entities as you don't have access to the `context` object like you know it from other types of schemas.

But don't worry, there is another way to achieve the same result by combining data from multiple source entities into a single view and returning it from the Query API. 

This is possible as the Query API is nicely integrated with the Delivery API, allowing you to request view data generated by the same source entities as the index items.

In this example, we will show you how to combine data from multiple source entities into a single view and return it from the Query API. In the example here we will use product source entities coming from a PIM system and price source entities coming from an ERP system.

## Presentation data from multiple source entities in a single view

First of all, we will create two full schemas. A price schema called `price` and a product schema called `product`.

The product schema will then reference the price schema using the `context.reference()` method. The result of this schema will be a product view that contains both product and price data.

<CodeGroup>
```js Product schema with price reference icon="square-js" highlight={14-15}
/** @type {Enterspeed.FullSchema} */
export default {
  triggers: function(context) {
    context.triggers("cms", ["pim", "product"]);
  },
  properties: function (sourceEntity, context) {
    return {
      sku: sourceEntity.properties.sku,
      name: sourceEntity.properties.name,
      categoryId: sourceEntity.properties.categoryId,
      brandId: sourceEntity.properties.brandId,
      image: sourceEntity.properties.image,
      description: sourceEntity.properties.description,
      price: context.reference('price')
                    .byOriginId(`price-${sourceEntity.properties.sku}`)
    };
  }
}
```

```js Price schema icon="square-js"
/** @type {Enterspeed.FullSchema} */
export default {
  triggers: function(context) {
    context.triggers("cms", ["erp", "price"]);
  },
  properties: function (sourceEntity, context) {
    return {
      salesPrice: sourceEntity.properties.salesPrice,
      listPrice: sourceEntity.properties.listPrice,
      currency: sourceEntity.properties.currency
    };
  }
}
```
</CodeGroup>

## The product index schema

In the index schema we only need the properties we need for filtering, sorting or facets, as the presentation data will be returned by the `product` schema above. In this example we only need the `sku`, `name` and `isActive` properties for filtering.

The alias of the Index schema is called `productIndex`.

<CodeGroup>
```js Product index schema icon="square-js"
/** @type {Enterspeed.IndexSchema} */
export default {
  triggers: function(context) {
    context.triggers('pim', ['product'])
  },
  index: {
    fields {
        sku: { type: "keyword" }, 
        name: { type: "text" },
        isActive: { type: "boolean" }
      }
  },
  properties: function (sourceEntity) {
    return {
        sku: sourceEntity.properties.sku, 
        name: sourceEntity.properties.name,
        isActive: sourceEntity.properties.isActive
      }
  }
}
```
</CodeGroup>

## The query and response

As the `product` schema and the `productIndex` schema are triggered by the same source entities, we can now request the `productIndex` from the [Query API](/api-reference/query) and have it returning the `product` view by using the `aliases` parameter.

Here's the query and response example.

<CodeGroup>
```bash Query API request highlight={1,14}
curl -L -X POST 'https://query.enterspeed.com/v1/productIndex' \
-H 'X-Api-Key: [your_environment_key]' \
-H 'Content-Type: application/json' \
-d '{
	"filters": {
    "and": [
          {
              "field": "isActive",
              "operator": "equals",
              "value": true
          }
      ]   
    },
    "aliases": ["product"],
    "pagination": {
      "page": 0,
      "pageSize": 20
    }
  }'
```
