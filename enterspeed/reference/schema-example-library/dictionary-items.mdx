Here's two examples of how you could handle dictionary items using either [Full schemas](/enterspeed/reference/js/full-schema/intro) or [Index schemas](/enterspeed/reference/js/index-schema/intro). 

These examples are based on the following dataset:

<AccordionGroup>
  <Accordion title="dictionaryRoot source entity">
    A single dictionaryRoot entity per culture.
    ```json
      {
        "type": "dictionaryRoot",
        "originId": "dictionaries-root-en-us",
        "properties": {
          "culture": "en-us"
        }
      }
    ```
  </Accordion>
  <Accordion title="dictionary source entity">
    Multiple dictionary entities per culture.
    ```json
      {
        "type": "dictionary",
        "originId": "ee1ae347-616f-4595-8fea-00a58f0238c0-en-us",
        "originParentId": "dictionaries-root-en-us",
        "properties": {
          "nodeId": 98,
          "key": "ButtonExit",
          "translation": "Exit",
          "culture": "en-us"
        }
      }
    ```
    ```json
      {
        "type": "dictionary",
        "originId": "dd1ae347-616f-4595-8fea-00a58f0238d1-en-us",
        "originParentId": "dictionaries-root-en-us",
    ```

## Using full schemas

<Note>
References has a limit of 500 items. If you have more than 500 dictionary items per culture, you could nest each dictionary items if they have a hierarchy and have the reprocess action reprocess the parent instead of the root as in the example below.
</Note>

<CodeGroup>
```js Breadcrumb item icon="square-js"
/** @type {Enterspeed.FullSchema} */
export default {
  triggers: function(context) {
    context.triggers("cms", ["cms", "dictionary"]);
  },
  actions: function (sourceEntity, context) {
    context.reprocess('dictionaryRoot').byOriginId(`dictionaries-root-${sourceEntity.properties.culture}`)
  },
  properties: function (sourceEntity, context) {
    return {
      key: sourceEntity.properties.key,
      translation: sourceEntity.properties.translation
    };
  }
}
```
</CodeGroup>

How the _breadcrumb item schema_ will be used in a page schema.

<CodeGroup>
```js Breadcrumb item used in another schema icon="square-js"
/** @type {Enterspeed.FullSchema} */
export default {
  triggers: function(context) {
    context.triggers("cms", ["cms", "dictionaryRoot"]);
  },
  routes: function(context) {
    context.handle(`dictionaries-${sourceEntity.properties.culture)}`)
  },
  properties: (sourceEntity, context) => ({
    translations: context.reference('dictionary').filter(`type eq 'dictionary' and properties.culture eq '${sourceEntity.properties.culture}'`)
  })
}
```
</CodeGroup>

The result of the above schemas can be seen here with a requests to the [Delivery API](/api-reference/delivery) and the response.

<CodeGroup>
```bash Request
curl -L -X GET 'https://delivery.enterspeed.com/v2?handle=dictionaries-en-us' \
-H 'X-Api-Key: [your_environment_key]'
```

## Using index schemas

<Note>
Index schemas are a paid add-on. But using index schemas doesn't have a limitation on items per culture, doesn't need reprocessing, but lets you query the index using the [Query API](/api-reference/query) for the items you want to return, e.g. based on culture.
</Note>

<CodeGroup>
```js Index schema with dictionary items icon="square-js"
/** @type {Enterspeed.IndexSchema} */
export default {
  triggers: function(context) {
    context.triggers('cms', ['dictionary'])
  },
  index: {
    fields {
        key: { type: "keyword" }, 
        translation: { type: "keyword" }, 
        culture: { type: "keyword" }
      }
  },
  properties: function (sourceEntity) {
    return {
        key: sourceEntity.properties.key, 
        translation: sourceEntity.properties.translation, 
        culture: sourceEntity.properties.culture
      }
  }
}
```
</CodeGroup>

The result of the above index schema can be seen here with a requests to the [Query API](/api-reference/query) and the response.

<CodeGroup>
```bash Query API request
curl -L -X POST 'https://query.enterspeed.com/v1/dictionaryIndex' \
-H 'X-Api-Key: [your_environment_key]' \
-H 'Content-Type: application/json' \
-d '{
	"filters": {
    "and": [
          {
              "field": "culture",
              "operator": "equals",
              "value": "en-us",
              "caseInsensitive": true
          }
      ]   
    },
    "pagination": {
      "page": 0,
      "pageSize": 1000
    }
  }'
```
